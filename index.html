Copying a whole following list

Profile → view all next to Following accounts → scroll that list all the way to the bottom until it stops loading, then select all and copy. Copying before it finishes scrolling only picks up the rows that happened to be on screen.

TikTok session (private accounts)

Private TikTok profiles only download if you are logged in. Take the login from a browser that is signed into TikTok and the app keeps its own copy of it, the way Instagram has its own sessions — so a download does not depend on that browser staying signed in. Public profiles need none of this.
