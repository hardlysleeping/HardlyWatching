HardlyWatching

This is the flatpak repository for HardlyWatching. It holds the packages only — the app's source, releases and screenshots are on GitHub.

Install HardlyWatching

That link opens your software installer. On a terminal it is:

flatpak install https://hardlysleeping.github.io/HardlyWatching/hardlywatching.flatpakref

Updates arrive with flatpak update. The app needs the org.gnome.Platform//49 runtime from Flathub, which the installer fetches automatically.
